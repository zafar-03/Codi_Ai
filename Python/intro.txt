Collection Data type : 
1. string    "char"
===========================================
2. list [] :
- accept anytype of data 
- modification allowed 
- duplicate value allowed
- index available
- add new data

ex : [11,12,13,11]
    if you want to access 12  : yourlistname[1]
===========================================
3. tuple() :
- accept anytype of data 
- modification not allowed 
- duplicate value allowed
- index available
- cann't add new data

ex : (11,12,13)
     if you want to access 12  : yourtuplename[1]
===========================================
4. set {} : 
- collection values(anytype of data) 
- modification allowed 
- duplicate value not allowed
- index not available
- add new data

ex : {11,12,13}
===========================================
5. dict   : {}  : collection of property(key + value)
{
    value1 : 11,
    value2 : 12,
    value3 : 13
}
